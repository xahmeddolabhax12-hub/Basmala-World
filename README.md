# Basmala Dream 💗

صفحة رومانسية تفاعلية باسم بسملة، مبنية باستخدام HTML وCSS وJavaScript فقط.

## الملفات
- `index.html` — هيكل الصفحة.
- `style.css` — التصميم والحركات والاستجابة للموبايل.
- `script.js` — الرسائل، الهدية، القلوب، القطة، والموسيقى.
- `assets/basmala-romantic-scene.png` — الصورة الرئيسية.

## التشغيل
افتح `index.html` باستخدام VS Code وLive Server، أو افتحه مباشرة في المتصفح.

## إضافة موسيقى اختيارية
ضع ملف MP3 تملك حق استخدامه داخل المجلد الرئيسي وسمّه `music.mp3`. زر الموسيقى سيشغّله ويوقفه.

## النشر على GitHub Pages
ارفع كل محتويات المجلد إلى جذر المستودع، ثم من Settings → Pages اختر:
- Source: Deploy from a branch
- Branch: main
- Folder: /(root)

ثم احفظ وانتظر اكتمال النشر.
